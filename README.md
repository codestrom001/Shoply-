🛍️ shoply 

A modern responsive e-commerce front-end website built with HTML, CSS, and JavaScript.
It includes product cards, shopping cart, favorites (wishlist), and modal-based UI — all running on the front end with local storage support.

🚀 Features
🧥 Modern landing page (Hero section)
🛒 Shopping cart system (with quantity & total price)
❤️ Favorites / Wishlist system (with images)
📱 Fully responsive design (mobile + desktop)
🎨 Clean red streetwear UI theme
🧾 Product grid layout
💾 LocalStorage support (data saved after refresh)
🪟 Modal popup cart & wishlist system
🍔 Mobile hamburger menu
